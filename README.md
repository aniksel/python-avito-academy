# python-avito-academy

Homework assignments for the Python course.

## Requirements

- Python 3.9 or newer

## Installing dependencies

No additional libraries are needed to run the code: it uses only
the Python standard library.

To check the code with linters:

```bash
pip install flake8 mypy
```

## Homework 1. Python basics

The `omd.py` file contains solutions to five tasks:

1. Comparing items in two warehouses
2. Analyzing search query history
3. Analyzing orders and returns
4. Daily store statistics
5. Analyzing product reviews

### Running

```bash
python omd.py
```

The program prints the results of all five tasks in order.

### Linting

```bash
flake8 .
mypy .
```
